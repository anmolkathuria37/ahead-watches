# AHED Watches – Frontend+Backend

Premium watch brand website built with a modern frontend stack.
This project powers the landing experience for **AHED Watches**, focusing on
luxury aesthetics, smooth motion, and high-performance UI.

---

## 🚀 Project Overview

This repository contains the frontend codebase for the AHED Watches website.
It is designed with a strong emphasis on:

- Minimal & luxury design
- Smooth animations (Framer Motion)
- High performance & scalability
- Clean and maintainable code

---

## 🛠 Tech Stack

This project is built using:

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion

---

## 📂 Project Setup (Local Development)

### Prerequisites

Make sure you have the following installed:

- Node.js (v18+ recommended)
- npm / pnpm / yarn

---

### Installation Steps

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Install dependencies
